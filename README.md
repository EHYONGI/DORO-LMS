# DORO-LMS
## 역할 분담
- 조장: 김아영
- 백엔드: 김동규, 왕 민, 종 열
- 프론트엔드: 박정연, 여민경
## 주요 기능
1. 사용자
    - 역할 기반 접근 제어: 관리자, 학습, 강사
    - 회원가입/로그인: JWT 기반 인증, 아이디/비밀번호 찾기(현재는 이메일 전송은 구현안됨)
    - 마이페이지: 개인정보 수정, 활동 내역, 수강 내역 확인
    - 역량 평가: DIMC 4가지 역량 점수 관리

2. 학생
    - 대시보드: 수강 중인 강의 목록, 최신 공지사항, 과제 목록 확인
    - 수강신청
        - 역량 점수에 따른 수강 자격 자동 확인
        - AI 맞춤 강의 추천: 사용자 역량 점수 기반 강의 추천
        - 관심 강의 담기
    - 학습 활동: 강의별 공지 확인, 과제 제출(파일 업로드 - 현재는 백엔드 안 `media`폴더에 저장됨), 출결 현황 조회
    - 상담 신청: 듣고 있는 수업의 강사에게 대면/비대면 상담 신청 및 상태 확인

3. 강사
    - 강의 관리: 담당 강의 목록 조회, 수강생 명단 확인
    - 출결 관리: 주차별 수강생 출결(출석, 지각, 결석) 입력 및 수정
    - 과제 관리: 과제 생성/수정, 학생 제출물 확인 및 채점(점수/피드백)
    - 공지 및 커뮤니티: 강의 공지사항 작성, 수강생 커뮤니티 관리
    - 상담 관리: 학생이 요청한 상담 승인/반려/완료 처리 및 일정 관리

4. 관리자
    - 사용자 관리: 전체 회원 조회 및 정보/권한 수정
    - 강의 개설 및 관리: 신규 강의 개설, 폐강, 강사 배정 및 지원자 승인
    - 전체 공지사항: 시스템 공지사항 작성 및 관리

5. 커뮤니티 & 공지
    - 게시판: 전체 게시판 및 강의별 전용 게시판
    - 공지사항: 시스템 전체 공지 및 강의별 공지 분리 운영
